Promotion 按鈕
跑馬燈

專案定位

  • 以 Game Plugin 形式掛載於 Stream n' Spin、IDN Slot 等既有專案
  • 與遊戲、SNS 共用，但與既有專案 隔離，不影響原本運作
  • 目標：增強榮耀系統，給予用戶 提升等級的目標

互動測試

  • 點 左上角狀態列 → 展開主選單
  • 狀態列右側 ‹ → 收合到畫面外，只露出 ›
  • 個人資料頁：頭像 / 稱號 / 背板選擇
  • 跑馬燈以「玩家 Chip」呈現（背板＋等級＋稱號＋名稱＋訊息）
  • 信箱可點訊息標為已讀；每日任務可領取 EXP

Status Bar 規格

  • 位置：左上角浮動，原規格 80×300（畫布內放大為 ~130×380）
  • 顯示：頭像（含 Lv 徽章）、名稱、稱號、EXP Bar、背板、未讀紅點
  • 不顯示：❌ 玩家 ID ❌ EXP 數字 ❌ 信箱 icon

主選單功能

  • 👤 個人資料 — 頭像 / 稱號 / 背板 / 暱稱
  • ✉️ 信箱 — 系統訊息、未讀數
  • 🏆 排行榜 — TurnOver / 得分（含名次、稱號、背板透出，不顯示 EXP）
  • 🎯 成就 / 任務 — 每日任務、遊戲攻略成就（6 階：銅/鐵/銀/白金/黃金/鑽石）
  • 🎰 機台選擇 — 等級解鎖（Lv5→5 台、Lv10→10 台），顯示 Turnover / Payout

跑馬燈動畫

  • 預設收合（水平壓縮＋淡出）
  • 有訊息時容器橫向展開彈跳出現（~0.45s）
  • 內容由右滑入到左單次播放（~6s）
  • 結束後收合消失（~0.45s），間隔 ~1.2s 後播下一則
  • 每次只顯示一則，不重複串接

成就範例

  • 彩金獵人（Payout 得分）：20K → 400K → 6M → 80M → 1B → 20B
  • 幸運兒（Payout 倍數）：20× → 50× → 100× → 150× → 250× → 500×
  • 遊戲攻略：梅杜莎獵手、TurnOver 達人、機台收藏家、連勝王 …
