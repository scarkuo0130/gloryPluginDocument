# 稱號系統 — 企劃規格

> - **文件性質**：企劃規格，描述系統「該做什麼、邏輯如何、結果為何」與驗收標準；不規範程式架構 / 命名。
> - **目的**：①程式人員實作參考　②QA 測試依據。
> - **數值聲明**：文內所有門檻 / 名次 / EXP / 數量皆為 **Prototype 展示預設值或 `TBD`**，正式值以「各項規格書」試算分頁與企劃拍板為準。
> - **資料來源**：成就系統項目表、稱號設定表、稱號名稱（Google 試算表「各項規格書」）。
> - **畫面對照**：`index.html` →〈個人資料〉頁「更換稱號」介面；成就頁「領取」。
> - **同步試算表分頁**：稱號名稱 / 稱號設定表。
> - **最後更新**：2026-06-08

## ■ 0. 系統概述

稱號是一種**可展示的身份獎勵**。玩家透過完成成就取得稱號資格，於成就頁領取後，可在〈個人資料〉的「更換稱號」介面選擇配戴，配戴後顯示於個人資訊與排行榜等對外露出的位置。

- **來源**：稱號一律來自**成就系統**（個人累積成就、月排行榜成就）。沒有其他取得管道。
- **語言**：對玩家顯示的稱號**只顯示英文名**（含品階羅馬數字，如 `Cash King Ⅹ`）。中文名（如「彩金風暴」）僅作為企劃 / 內部對照，不對玩家露出。
- **族系與品階**：每個稱號是一個「族系名 + 品階」的組合。品階由低到高以羅馬數字表示：

  | 品階 | 銅1 | 銅2 | 鐵1 | 鐵2 | 銀1 | 銀2 | 白金1 | 白金2 | 黃金 | 鑽石 |
  |---|---|---|---|---|---|---|---|---|---|---|
  | 標記 | Ⅰ | Ⅱ | Ⅲ | Ⅳ | Ⅴ | Ⅵ | Ⅶ | Ⅷ | Ⅸ | Ⅹ |

  （並非每個族系都有完整 10 階；實際階數以成就設定為準。）

## ■ 1. 介面操作

| 區塊 / 操作 | 玩家操作 | 系統結果 / 回饋 |
|---|---|---|
| 成就頁領取稱號 | 達成成就後，於成就頁點該成就「領取」 | 將該稱號加入玩家「已擁有稱號」；未領取者不視為已擁有 |
| 進入更換稱號 | 〈個人資料〉點「更換稱號」 | 開啟稱號選單，列出可配戴的稱號 |
| 選稱號 | 點選單中某一稱號 | 設為目前配戴稱號、關閉選單、更新個人資訊顯示 |
| 未配戴 | —（初始或當月稱號失效後） | 稱號欄留空、不顯示 |
| 對外顯示 | —（自動） | 個人資訊 / 排行榜等位置顯示目前配戴稱號（英文＋品階） |

### 1.1 更換稱號選單的顯示規則

1. **只列出已擁有（已領取）的稱號**；未達成或已達成但未領取者不出現。
2. **每個族系只顯示「目前已擁有的最高品階」一項**。
   - 例：玩家同時擁有 `Level King Ⅴ`、`Level King Ⅵ`，選單**只顯示 `Level King Ⅵ`**，不列出 Ⅴ。
3. 玩家擁有多個**不同族系**時，每個族系各列出一項（各自的最高階）。
   - 永久版與當月版為**不同族系、不同名稱**（如 `Cash King` 與 `Fortune King`），兩者各自獨立列在選單。
4. **不提供「無」作為稱號項目**。「無稱號」不是一種稱號；未配戴任何稱號時，個人資訊的稱號欄**留空、不顯示**（新玩家初始即為此狀態）。

### 1.2 稱號狀態

| 狀態 | 說明 |
|---|---|
| 未擁有 | 對應成就未達成、或達成但未於成就頁領取；不出現在更換選單 |
| 已擁有・未配戴 | 已領取、可於更換選單選擇 |
| 已擁有・配戴中 | 目前顯示於個人資訊 / 對外位置的稱號 |
| 當月有效・已失效 | 月排行榜類稱號跨月後失效（見 §3）；失效後不再出現在更換選單 |

## ■ 2. 功能流程

| 流程 | 步驟 | 說明 |
|---|---|---|
| 取得稱號 | 1. 達成成就 | 依成就條件達成（累積門檻或月排行名次） |
| | 2. 領取 | 於成就頁領取，稱號入庫為「已擁有」 |
| | 3. 進更換選單 | 該族系以「已擁有最高階」呈現於更換選單 |
| 配戴稱號 | 1. 開更換選單 | 列出各族系最高階 +「無」 |
| | 2. 選擇 | 設為配戴、立即更新對外顯示 |
| 升階（同族系達更高階） | 達成並領取更高階 | 更換選單該族系改顯示新最高階；**已配戴的稱號不自動升階**，維持原配戴，需玩家自行重新選擇。升階提示由**成就頁本身呈現**（顯示下一個可達成的稱號），不另設升階提示 |
| 月排行稱號失效 | 跨月結算 | 月排行榜類稱號僅當月有效，次月失效、退出更換選單。**失效時若正在配戴 → 自動卸下，稱號欄留空、不顯示**（不自動回退到其他稱號） |

### 2.1 升階行為（重點邏輯）

- 假設玩家已配戴 `Level King Ⅴ`，之後達成並領取 `Level King Ⅵ`：
  - 更換選單該族系 **只顯示 `Level King Ⅵ`**（Ⅴ 不再列出）。
  - 目前配戴**維持 `Level King Ⅴ` 不變**，系統不自動換成 Ⅵ。
  - 玩家若想顯示 Ⅵ，需自行進更換選單重新選取。
  - 結果：可能出現「配戴中的階低於選單可選的最高階」這種狀態，屬正常。

## ■ 3. 資料設定

### 3a. 稱號需具備的資訊

| 資料項 | 意義 |
|---|---|
| 族系名（英文） | 對玩家顯示的稱號名（如 Cash King） |
| 品階 | Ⅰ～Ⅹ，對應成就品質（銅1～鑽石） |
| 來源成就 | 此稱號由哪個成就授予 |
| 效期 | 永久 / 當月有效（見下表） |
| 取得條件 | 累積門檻或月排行名次（值見成就設定表） |

### 3b. 效期分類（重點規則）

| 來源類型 | 效期 | 範例族系 |
|---|---|---|
| 個人累積成就 | **永久保留**（達成最高階後永久擁有） | 等級達成、累積 Payout、累積 Spin 次數、單局勝分倍率、連續/累積每日任務 |
| 月排行榜成就 | **僅當月有效**（次月失效，需重新達成） | 等級排名、月累積 Payout、單局最高勝分、月累積 Spin 次數、月累積總勝倍率、單局最高勝分倍率 |

### 3c. 稱號族系與來源對照（定案）

> 永久版與當月版同概念但**已拆為不同名稱**，互不合併。

| 中文族系 | 來源成就（項目） | 效期 | 英文名 |
|---|---|---|---|
| 籌碼傳奇 | 等級達成 | 永久 | Level King |
| 連日長紅 | 連續完成每日任務 | 永久 | Streak Master |
| 每日開盤 | 累積完成每日任務 | 永久 | Task Master |
| 單局封王 | 單局勝分倍率 | 永久 | Mega Win |
| 彩金風暴 | 累積 Payout | 永久 | Cash King |
| 幸運轉輪 | 累積 Spin 次數 | 永久 | Spin Master |
| TOP | 等級排名（月榜） | 當月 | Rank King |
| 彩金風暴 | 月累積 Payout（月榜） | 當月 | Fortune King |
| 單局封王 | 單局最高勝分（月榜） | 當月 | Top Win |
| 幸運轉輪 | 月累積 Spin 次數（月榜） | 當月 | Spin King |
| 爆倍盛宴 | 月累積總勝倍率（月榜） | 當月 | Combo King |
| 神倍時刻 | 單局最高勝分倍率（月榜） | 當月 | Mega Multiplier |

**同概念拆名對照**：永久 `Cash King` ↔ 當月 `Fortune King`／永久 `Spin Master` ↔ 當月 `Spin King`／永久 `Mega Win` ↔ 當月 `Top Win`／永久 `Level King` ↔ 當月 `Rank King`。

### 3d. 品階 → 羅馬數字對應

銅1=Ⅰ、銅2=Ⅱ、鐵1=Ⅲ、鐵2=Ⅳ、銀1=Ⅴ、銀2=Ⅵ、白金1=Ⅶ、白金2=Ⅷ、黃金=Ⅸ、鑽石=Ⅹ。
顯示格式＝「英文族系名 + 半形空格 + 羅馬數字」，例：`Cash King Ⅱ`、`Mega Win Ⅹ`。

## ■ 4. 與上層企劃待對齊

| 項目 | 說明 |
|---|---|
| 連簽獎勵展示性 | 每日簽到企劃提到連簽應給「稱號 / 背板」等可展示獎勵；目前連簽主給 EXP，稱號授予方式待對齊。 |

## ■ 6. 規則決策紀錄（已拍板）

| # | 項目 | 決策 |
|---|---|---|
| D1 | 對玩家顯示語言 | 只顯示英文（含品階羅馬數字）；中文名僅內部對照 |
| D2 | 月排行榜類稱號效期 | 僅當月有效，次月失效需重新達成 |
| D3 | 同族系達更高階時的配戴行為 | 維持原配戴，不自動升階；選單只顯示最高階 |
| D4 | 更換選單顯示範圍 | 只顯示「每族系已擁有的最高品階」一項 + 「無」 |
| D5 | 稱號來源 | 一律來自成就系統，須於成就頁領取後才視為已擁有 |
| D6 | 同名是否合併 | **不合併**；同名但不同來源 / 效期者拆成不同名稱（見 D7） |
| D7 | 同概念拆名 | 永久 ↔ 當月：Cash King↔Fortune King／Spin Master↔Spin King／Mega Win↔Top Win／Level King↔Rank King |
| D8 | 當月稱號失效且配戴中 | 自動卸下，稱號欄留空、不顯示（不回退到其他稱號） |
| D9 | 升階提示 | 由成就頁本身呈現（顯示下一個可達成的稱號），不另設升階提示 |
| D10 | 「無稱號」 | 不是稱號項；未配戴時稱號欄留空、不顯示 |

## ■ QnA（已決議，供追溯）

| # | 工程師 / QA 會問 | 決議 |
|---|---|---|
| Q1 | 衝突的 4 組（永久 vs 當月排行）當月版叫什麼？ | 永久維持原名；當月版＝Rank King / Fortune King / Top Win / Spin King（見 D7）。已回填稱號名稱、稱號設定表。 |
| Q2 | 月排行稱號跨月失效、且玩家正配戴時畫面如何處理？ | **自動卸下，稱號欄留空、不顯示**（D8）。 |
| Q3 | 達成成就後是否須手動領取才入庫？ | 須領取才算已擁有（D5）；升階/可領狀態由成就頁呈現（D9）。 |
| Q4 | 升階後「配戴階低於選單最高階」需提示嗎？ | 不另設提示；成就頁本身已顯示下一個稱號（D9）。 |
| Q5 | 永久版與當月版兩者如何在選單呈現？ | 已拆名為不同族系，各自獨立列一項（D4 + D7）。 |
| Q6 | 永久 / 當月品階 Ⅰ～Ⅹ 意義不同，UI 是否需區分？ | 已透過拆名區分，品階羅馬數字不另標示。 |
| Q7 | 「無稱號」是否為一種稱號 / 預設值？ | 不是稱號項；未配戴時稱號欄留空（D10），新玩家初始即留空。 |

## ■ 5. QA 驗收清單

- [ ] 1. 成就未領取前，更換選單**不出現**該稱號。
- [ ] 2. 成就頁領取後，該稱號出現在更換選單。
- [ ] 3. 同族系擁有多階時，選單**只顯示最高階**一項（如 Ⅴ、Ⅵ 並存只顯示 Ⅵ）。
- [ ] 4. 擁有多個不同族系時，每族系各列一項（各自最高階）。
- [ ] 5. 未配戴任何稱號時，稱號欄留空、不顯示；選單**不含「無」項**。
- [ ] 6. 選某稱號後，個人資訊 / 對外位置即時更新為該稱號（英文 + 羅馬數字）。
- [ ] 7. 對玩家顯示一律英文名，不出現中文族系名。
- [ ] 8. 顯示格式為「英文名 空格 羅馬數字」（如 `Cash King Ⅱ`）。
- [ ] 9. 已配戴 Ⅴ 後達成並領取 Ⅵ：配戴**維持 Ⅴ**，選單該族系顯示 Ⅵ。
- [ ] 10. 月排行榜類稱號達成當月可配戴；**跨月後失效**、退出更換選單。
- [ ] 11. 配戴中的當月稱號跨月失效時，**自動卸下、稱號欄留空**，不回退到其他稱號。
- [ ] 12. 永久類稱號達成後永久保留，跨月不失效。
- [ ] 13. 玩家名稱 / 稱號含特殊字元時不破版、無 XSS。
- [ ] 14. 永久版與當月版同概念稱號使用**不同名稱**（如 Cash King vs Fortune King），玩家不會混淆。
- [ ] 15. 新玩家初始無配戴，稱號欄留空。
