## 0. 頁面概述

「每日任務」頁由上而下分兩塊：

1. **連簽月曆**（上）— 以月曆呈現連續登入達成狀況與每週 / 全勤獎勵。
2. **今日任務清單**（下）— 當日可完成的任務與領取。

## 1. 介面操作

| 區塊 | 玩家操作 | 系統結果 / 回饋 |
|---|---|---|
| 進入頁面 | 由主選單點「每日任務」 | 開啟每日任務頁 |
| 連簽月曆 | 檢視月曆 | 顯示當月日曆，每日格子呈現狀態：已完成 / 漏簽 / 今天 |
| 連簽月曆 | 點該週「領取」 | 該週全達成→發該週獎勵、提示成功、按鈕轉為已領取；有漏簽→按鈕為「未達成」且不可領 |
| 連簽月曆 | 點「四週額外獎勵」領取 | 28 天全勤才可領，發放全勤獎 |
| 今日任務 | 檢視任務 | 每筆顯示名稱、進度條與「目前 / 目標」 |
| 今日任務 | 點任務「領取」 | 給予該任務 EXP、提示成功音效與文字、按鈕轉為已領取 |
| 連動回饋 | （自動） | 主選單的每日任務項顯示可領紅點與完成進度；全部領完顯示已完成 |

### 連簽月曆
> 📷 `temp/每日任務截圖/02-連簽月曆.png`

- 以「週」為單位排列，4 週共 28 天。
- 每日格子三種狀態：**已完成**、**漏簽**（中斷該段連續）、**今天**。
- 每週對應一個獎勵；四週全到齊另有一個全勤大獎。

### 今日任務清單
> 📷 `temp/每日任務截圖/03-任務清單.png`

- 每筆任務：名稱 + 進度條 + 「目前 / 目標」文字 + 領取按鈕。
- 領取按鈕三態：**可領取**、**已領取**、**未完成（不可點）**。

## 2. 功能流程

### 2.1 每日任務領取
1. 玩家於遊戲中累積進度，達到任務目標 → 任務變為**可領取**。
2. 玩家點領取 → 任務變為**已領取**。
3. 系統發放該任務 EXP（計入等級系統），播放成功回饋。
4. 畫面即時更新任務狀態與主選單的紅點 / 進度。

### 2.2 連簽獎勵領取
1. **當日達成判定**：當天「所有每日任務皆已領取」才算當日完成，當日格子點亮。
2. **整週判定**：某週 7 天皆完成且無漏簽 → 該週獎勵可領取。
3. **領取週獎**：發放該週獎勵，按鈕轉為已領取。
4. **斷簽**：該週任一天漏簽 → 該週獎勵鎖定為「未達成」，**不可補領**。
5. **全勤獎**：連續 28 天全部完成 → 可領四週全勤額外獎。

### 2.3 每日重置（`TBD`）
- 預設每日 00:00（伺服器時區）重置：未完成任務進度歸零、任務狀態重置。
- 重置時區、已完成未領取的處理方式待企劃拍板（建議：保留可領至下次重置前）。

## 3. 資料設定

### 3a. 每日任務（每筆任務需具備的資訊）

| 資料項 | 意義 |
|---|---|
| 任務名稱 | 顯示給玩家的任務標題 |
| 完成條件 | 達成所需的目標（如「Spin 10 次」「Win 1 次」） |
| 目前進度 / 目標值 | 用於進度條與「目前 / 目標」顯示 |
| EXP 獎勵 | 完成領取後給予的經驗值 |
| 狀態 | 可領取 / 已領取 / 未完成 |

**Prototype 展示任務（預設值，待企劃替換）：**

| 任務 | 完成條件 | EXP |
|---|---|---|
| 登入打卡 | 登入 1 次 | 50 |
| Spin 10 次 | 累計轉 10 次 | 80 |
| Win 1 次 | 中獎 1 次 | 120 |

### 3b. 連簽獎勵（展示用預設值，待企劃拍板）

| 達成 | 獎勵 |
|---|---|
| 第 1 週全勤 | EXP +500 |
| 第 2 週全勤 | EXP +1,000 |
| 第 3 週全勤 | EXP +1,500 |
| 第 4 週全勤 | EXP +2,000 |
| 28 天全勤 | 頭像（全勤限定） |

### 3c. 連簽規則參數

| 參數 | 值 |
|---|---|
| 每段（週）天數 | 7 |
| 連簽總天數 | 28（4 週） |
| 「當日完成」定義 | 當天所有每日任務皆已領取 |
| 斷簽影響 | 漏簽當週獎勵不可領、不可補 |

## 4. 與上層企劃的待對齊項

> 以下為本頁與既有企劃文件方向尚未對齊之處，供企劃確認後調整。

1. **連簽獎勵的展示性**：目前展示版連簽獎勵以 EXP 為主；`榮耀系統目標與需求.md` 強調連簽應給**稱號 / 背板**等可展示身份的獎勵。是否調整由企劃定。
2. **每日任務 EXP 配額**：`等級系統企劃.md` 規劃「每日任務 EXP 佔總成長之固定比例、隨時間累進」；本頁任務 EXP 尚未依該模型配置，待企劃給定每日任務 EXP 配額表。
3. **任務內容與數量**：展示版僅 3 筆示意；正式任務清單（登入、首抽、累計把數、累計 turnover、特定機台等）待企劃拍板。
