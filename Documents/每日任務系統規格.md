## 1. 介面操作

| 區塊 | 玩家操作 | 系統結果 / 回饋 |
|---|---|---|
| 進入頁面 | 由主選單點「每日任務」 | 開啟每日任務頁，預設停在「本月」 |
| 月份頁籤 | 點「上個月 / 本月」切換 | 切換月曆檢視月份；最多回看上個月 |
| 連簽月曆 | 檢視月曆 | 顯示該月日曆（1 日～最後一天），每日格子呈現狀態：已完成 / 漏簽 / 今天 |
| 連簽月曆 | 點該週「領取」 | 該週 7 天全到→發**固定**週獎勵、提示成功、按鈕轉為已領取；有漏簽→按鈕為「未達成」且不可領 |
| 連簽月曆 | 點「月全勤額外獎勵」領取 | **當月每天**皆登入才可領，發放月全勤獎 |
| 今日任務 | 檢視任務 | 每筆顯示名稱、進度條與「目前 / 目標」（**僅本月顯示**） |
| 今日任務 | 點任務「領取」 | 給予該任務 EXP、提示成功音效與文字、按鈕轉為已領取 |
| 連動回饋 | （自動） | 主選單的每日任務項顯示可領紅點與完成進度；全部領完顯示已完成 |

### 1.0 月份頁籤（上個月 / 本月）

- 月曆上方有 **「上個月」「本月」兩頁籤**，預設選「本月」。**最多只能回看上個月**（不可再往前）。
- **上個月有「達成未領」的獎勵時**，「上個月」頁籤右上顯示**紅點**提示玩家切過去領。
- **切到「上個月」時，下方「今日任務清單」隱藏**（上個月不能再做任務，只供檢視 / 補領連簽獎勵）。

> 📷 上個月檢視：`狀態-月曆-上個月.png`（含 3 個可領週獎 + 月全勤獎，且下方無任務清單）

### 1.1 連簽月曆 — 產生規則

- **月曆 = 自然月**：呈現該月 1 日～最後一天，標準月曆格（週日→週六為一列）。月初 1 日之前、月末最後一天之後的位置留**空白格**。
- 月份天數依該月為準（28～31 天），故月曆有 **4～6 列（週）**。
- 月曆標題顯示年月（如「2026 年 5 月」）。
- 每一**整週列**（該列 7 天皆屬當月）下方一顆「該週獎勵」按鈕；月曆最下方一顆「月全勤額外獎勵」按鈕。
- **月初 / 月末未滿 7 天的列**：不提供週獎勵按鈕，顯示「本週未滿 7 天，無週獎勵」。（這些日仍計入月全勤；未來以「補打卡」機制讓玩家補上，見 §3d。）

### 1.2 連簽月曆 — 日期格子狀態

每一個日期格子可能呈現下列狀態（皆見 `狀態-月曆-當月.png`）：

| 狀態 | 顯示 | 說明 |
|---|---|---|
| 已完成 | 綠色填滿 | 該日**有登入**即算完成 |
| 未到（未來日） | 無填色 | 尚未到的日期，無法達成 |
| 漏簽 | 紅底 + 標記 | 該日未登入，**中斷連續**，使該週無法領獎、並使當月月全勤失敗 |
| 今天 | 金框 + 綠色填滿 | 今天有登入即算完成（登入即算，與每日任務脫鉤） |
| 空白格 | 透明 | 非當月日期（補滿週列用） |

### 1.3 連簽領取按鈕狀態（週獎勵 / 月全勤）

> 週獎勵為**固定值、不累積**（每整週相同）。

| 按鈕狀態 | 顯示文字 | 條件 |
|---|---|---|
| 可領取 | 「領取 EXP +N」（亮色） | 該整週 7 天全到且無漏簽 |
| 尚未達成 | 「尚未達成」（灰、不可點） | 該週尚有日期未完成、且無漏簽 |
| 未達成（鎖定） | 「未達成」（灰、不可點） | 該週有漏簽 → 無法領、不可補（補打卡機制未來規劃，見 §3d） |
| 已領取 | 「已領取 EXP +N」（不可點） | 已領過 |
| （未滿週列） | 「本週未滿 7 天，無週獎勵」 | 月初/月末未滿 7 天的列 |

> 📷 完整月曆（含已完成 / 漏簽鎖定週 / 未滿週 / 各週領取按鈕）：`狀態-月曆-當月.png`（本月）、`狀態-月曆-上個月.png`（上個月，獎勵可領）

### 1.4 今日任務清單 — 任務狀態

每筆任務：名稱 + 進度條 + 「目前 / 目標」文字 + 領取按鈕。按鈕三態：

| 任務狀態 | 顯示文字 | 玩家可操作 | 說明 |
|---|---|---|---|
| 未完成 | 「未完成」（灰、不可點） | 否 | 進度未達目標（如 4 / 10），進度條呈部分填滿 |
| 已完成 · 可領取 | 「領取 +N EXP」（金色亮鈕） | 是 | 進度達標、尚未領取 |
| 已提領 | 「✓ 已領取」（綠字、不可再點） | 否 | 已領過，EXP 已發放 |

> 📷 三態同畫面對照：`狀態-任務三態.png`
>（圖中：登入打卡＝可領取 / Spin 10 次＝已提領 / Win 1 次＝未完成）

### 1.5 「登入打卡」未領 vs 已領 對照

| 情境 | 畫面 | 對應截圖 |
|---|---|---|
| 達標未領 | 顯示金色「領取 +50 EXP」按鈕，進度條滿格 | `狀態-打卡未領.png` |
| 已領取 | 按鈕轉為綠字「✓ 已領取」、不可再點，進度條維持滿格 | `狀態-打卡已領.png` |

## 2. 功能流程

### 2.1 每日任務領取
1. 玩家於遊戲中累積進度，達到任務目標 → 任務變為**可領取**。
2. 玩家點領取 → 任務變為**已領取**。
3. 系統發放該任務 EXP（計入等級系統），播放成功回饋。
4. 畫面即時更新任務狀態與主選單的紅點 / 進度。

### 2.2 連簽獎勵領取
1. **當日達成判定**：玩家當天**有登入**即算當日完成（登入即算，與每日任務脫鉤），當日格子點亮。
2. **整週判定**：某整週列（7 天）皆完成且無漏簽 → 該週固定獎勵可領取。
3. **領取週獎**：發放該週固定獎勵（不累積），按鈕轉為已領取。
4. **斷簽**：該週任一天漏簽 → 該週獎勵鎖定為「未達成」，**不可補領**（補打卡機制未來規劃）；且該漏簽使**當月月全勤失敗**。
5. **月全勤獎**：當月**每一天**皆登入 → 可領月全勤額外獎。
6. **跨月**：上個月未領的週獎 / 月獎**保留可補領**（切「上個月」頁籤領取）；月全勤獎**每月可重複取得**。

### 2.3 每日重置（`TBD`）
- 預設每日 00:00（伺服器時區）重置：未完成任務進度歸零、任務狀態重置。
- 重置時區、已完成未領取的處理方式待企劃拍板（建議：保留可領至下次重置前）。

## 3. 資料設定

### 3a. 每日任務（每筆任務需具備的資訊）

| 資料項 | 意義 |
|---|---|
| 任務名稱 | 顯示給玩家的任務標題 |
| 完成條件 | 達成所需的目標（如「Spin 10 次」「Win 1 次」） |
| 目前進度 / 目標值 | 用於進度條與「目前 / 目標」顯示 |
| EXP 獎勵 | 完成領取後給予的經驗值 |
| 狀態 | 可領取 / 已領取 / 未完成 |

**Prototype 展示任務（預設值，待企劃替換）：**

| 任務 | 完成條件 | EXP |
|---|---|---|
| 登入打卡 | 登入 1 次 | 50 |
| Spin 10 次 | 累計轉 10 次 | 80 |
| Win 1 次 | 中獎 1 次 | 120 |

### 3b. 連簽獎勵（展示用預設值，待企劃拍板）

| 達成 | 獎勵 | 備註 |
|---|---|---|
| 每整週全勤（7 天皆登入） | EXP +30,000 | **固定值、不累積**（每整週相同） |
| 當月全勤（每天皆登入） | EXP +600,000 | 月全勤額外獎，**每月可重得**，取代舊「28 天全勤」 |

> 連簽獎勵的展示性方向（是否改給稱號 / 背板）見 §4。

### 3c. 連簽規則參數

| 參數 | 值 |
|---|---|
| 週期單位 | 自然月（當月 1 日～最後一天） |
| 月曆列數 | 4～6 列（依當月天數，週日→週六為一列） |
| 可檢視範圍 | 上個月 / 本月（頁籤切換，最多回看上個月） |
| 「當日完成」定義 | **當天有登入即算**（與每日任務脫鉤） |
| 週獎勵條件 | 該整週列 7 天皆登入；月初/月末未滿 7 天的列不給週獎（待補打卡補上） |
| 週獎勵 | EXP +30,000，**固定值、不累積** |
| 月全勤獎條件 | 當月每一天皆登入（漏一天即失敗） |
| 月全勤獎 | EXP +600,000，**每月可重得** |
| 斷簽影響 | 漏簽當週獎勵不可領、不可補；並使當月月全勤失敗 |
| 跨月處理 | 上個月未領獎勵保留可補領；上個月有未領 → 頁籤紅點提示 |
| 上個月檢視 | 隱藏下方今日任務清單（僅供檢視 / 補領連簽獎勵） |

### 3d. 補打卡機制（未來規劃）

> 規劃中：允許玩家「補打卡」補回漏簽的日期，使該日重新計入連續達成。具體規則（可補天數上限、是否消耗道具 / 付費、補打卡時限、是否影響月全勤判定等）**待企劃定義**，本版尚未實作。

> 以下為本頁與既有企劃文件方向尚未對齊之處，供企劃確認後調整。

1. **連簽獎勵的展示性**：目前展示版連簽獎勵以 EXP 為主；`榮耀系統目標與需求.md` 強調連簽應給**稱號 / 背板**等可展示身份的獎勵。是否調整由企劃定。

3. **任務內容與數量**：展示版僅 3 筆示意；正式任務清單（登入、首抽、累計把數、累計 turnover、特定機台等）待企劃拍板。

## 5. QA 驗收清單

- [ ] 由主選單可正確進入每日任務頁，預設停在「本月」。
- [ ] 上個月 / 本月頁籤可切換；**最多只能回看上個月**。
- [ ] 上個月有「達成未領」獎勵時，「上個月」頁籤顯示**紅點**；領完後紅點消失。
- [ ] 切到「上個月」時，下方今日任務清單**隱藏**；切回「本月」恢復顯示。
- [ ] 連簽月曆顯示該月（1 日～最後一天），列數依當月天數正確（4～6 列），月外位置為空白格。
- [ ] 月曆標題顯示正確年月。
- [ ] 每日狀態（已完成 / 漏簽 / 今天 / 未來日 / 空白）顯示正確。
- [ ] 「當日完成」＝**當天有登入即算**（不需完成每日任務）。
- [ ] 整週列（7 天）全到且無漏簽 → 該週固定獎勵（EXP +30,000）可領；每整週相同（不累積）；領取後不可重複領。
- [ ] 該週有任一天漏簽 → 該週獎勵顯示「未達成」且無法領取、無法補領。
- [ ] 月初 / 月末未滿 7 天的列 → 顯示「本週未滿 7 天，無週獎勵」，無領取按鈕。
- [ ] 當月每一天全到 → 月全勤額外獎（EXP +600,000）可領；漏任一天即月全勤失敗。
- [ ] 月全勤獎每月可重複取得；上個月未領獎勵保留可於上個月頁籤補領。
- [ ] 每日任務達標後才可領取；領取後狀態轉為已領取、給予對應 EXP。
- [ ] 未達標任務顯示為未完成且不可領取。
- [ ] 領取任務 / 連簽獎勵後，主選單紅點與完成進度即時更新；全部領完顯示已完成。
- [ ] 每日重置後（規則確認後）任務進度與狀態正確歸零。
- [ ] 任一畫面不顯示 EXP 數字（沿用狀態列規格，僅以 Bar 比例呈現）；任務「+N EXP」僅為領取回饋文案。
- [ ] 玩家名稱等動態文字正確顯示，含特殊字元不破版、無 XSS。
