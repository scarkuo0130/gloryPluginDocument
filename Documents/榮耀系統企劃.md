# 榮耀系統企劃

> 文件建立日期：2026-04-27
> 狀態：草稿（持續更新中）

---

## 專案背景

為既有運行中的專案（如 Stream n' Spin 直播平台、IDN Slot 等遊戲產品）額外掛上一套**共用榮耀系統**。

### 既有專案參考畫面
1. **直播間畫面**（Stream n' Spin）
   - 包含遊戲畫面、聊天室、下注控制（Bet / Auto Spin / Play）、餘額顯示
2. **平台首頁**（Stream n' Spin）
   - Streaming Now 直播列表、Promotion 活動、All Streamers 主播列表
3. **遊戲畫面**（IDN Slot - Wonderland）
   - 老虎機遊戲，含 Saldo（餘額）、Taruhan（下注）、Kemenangan（贏分）

---

## 製作方式

以 **Game Plugin** 形式開發：
- 與遊戲、SNS（Stream n' Spin）**共用**
- 與既有專案**隔離**，不影響原本專案運作
- 可掛載於不同產品上

## 一、榮耀系統相關

### 目標
增強榮耀系統的內容，給予用戶**提升等級的目標**。

### 功能規劃

#### 1. 會員設置
- 頭像
- 稱號（Title，介於頭像與背板選擇之間）
- 背板（含內框描邊、四角裝飾、主題化色彩）

**背板主題（範例）：**
- 日落（紫橘紅漸層 + 太陽光暈）
- 星河（深紫 + 星點）
- 海洋（藍綠 + 斜紋波浪）
- 翡翠（深綠 + 對角紋路）
- 暗夜（深藍紫 + 月亮）
- 熔岩（紅黑 + 火焰光斑）— 鎖定
- 黃金（金色 + 亮紋）— 鎖定

#### 2. 跑馬燈
- 中大獎廣播
- 進入排行榜顯示

**跑馬燈個人訊息顯示內容：**
每筆個人訊息以「玩家 Chip」形式呈現，包含：
- 背板（作為 Chip 的底色）
- 等級徽章（Lv.XX，金色）
- 稱號（Title chip）
- 玩家名稱
- 訊息內容（例：中得 100,000,000）

**跑馬燈開合動畫：**
- 預設狀態：marquee 為**收合**（水平壓縮在中央 + 淡出，不可見）
- 有訊息要播放時，marquee 容器以橫向展開的彈跳動畫**出現**（約 0.45s）
- 容器展開後，內容由右滑入到左單次滑動（約 6s）
- 訊息播放結束後，marquee 收合**消失**（約 0.45s）
- 間隔約 1.2s 後，自動播放下一則訊息（循環）
- 每次只顯示**一則**訊息，不重複串接

#### 3. 排行榜
- TurnOver 排行榜
- 得分排行榜

**排行榜每筆項目顯示資訊：**
- 名次（前三名特殊樣式 🥇🥈🥉）
- 玩家頭像
- 玩家背板（作為列底色透出）
- 玩家稱號（Title chip）
- 玩家名稱
- 玩家等級
- 排行數值（TurnOver / 得分）
- ※ **不顯示經驗值**

#### 4. 選台子擴增
- 等級 5 → 有 5 台可以選
- 等級 10 → 有 10 台可以選
- 可以看到（假）機台成績資訊，例如：
  - 前七日 TurnOver
  - Total Win

**機台選擇頁版面：**
- 頁面最上方顯示「**目前機台**」大卡片：
  - 機台編號（#XX）
  - 資料區間（YYYY-MM-DD ~ YYYY-MM-DD）
  - Turnover
  - Total Win
- 分隔線後方為「可選機台清單」，每筆顯示：
  - 機台編號
  - 資料區間
  - Turnover
  - Total Win
- 點擊清單中任一台 → 將該台資料替換到頂部「目前機台」卡片
- 機台不顯示圖片，純文字呈現

#### 5. 成就系統

**成就分類**
- 成就系統的分類方式與排行榜雷同：
  - 總成就
  - 各別遊戲成就
- 總成就用來累積跨遊戲、跨場景的整體表現。
- 各別遊戲成就用來強化單一遊戲的攻略感與專屬榮耀感。

**成就階級**
- 每個成就皆有 6 個等級。
- 階級由低到高為：
  - 銅
  - 鐵
  - 銀
  - 白金
  - 黃金
  - 鑽石
- 同一個成就依不同門檻往上累積，玩家可逐級提升。

**每日任務**
- 設定任務給予經驗值

**遊戲攻略成就**
- TurnOver 打滿 → 給予頭像與背板
- 派彩倍數達成 → 給予頭像與背板

**數值型成就範例**

1. 彩金獵人（Payout 得分）
   - 銅：20,000 分
   - 鐵：400,000 分
   - 銀：6,000,000 分
   - 白金：80,000,000 分
   - 黃金：1,000,000,000 分
   - 鑽石：20,000,000,000 分

2. 幸運兒（Payout 倍數）
   - 銅：20 倍
   - 鐵：50 倍
   - 銀：100 倍
   - 白金：150 倍
   - 黃金：250 倍
   - 鑽石：500 倍

**遊戲攻略成就 — 範例清單**
| 成就名稱 | 條件 | 獎勵 |
|---------|------|------|
| 梅杜莎獵手 | 在「梅杜莎」達成 Win x 50 | 頭像 🐍 梅杜莎 |
| Tiger Cop 獵手 | 在「Tiger Cop」達成 Win x 50 | 頭像 🐯 老虎 |
| TurnOver 達人 | 單日 TurnOver 1,000,000 | 頭像 🐲 + 背板 熔岩 |
| 幸運大獎 | 單局派彩 500x | 頭像 👑 + 稱號「幸運兒」 |
| 機台收藏家 | 解鎖 20 台機台 | 頭像 🎰 + 背板 賭場 |
| 連勝王 | 連續贏取 10 次 | 頭像 🔥 + 稱號「不敗」 |
| 直播之星 | 累積在直播間下注 100 萬 | 頭像 🌟 + 背板 星河 |

## 系統架構

### 整合方式
以**浮動式 UI**形式掛在既有專案上。

### 設計畫布
- **解析度：720 × 1280（直式）**
- 暫不處理橫式

### Account Status Bar（帳號狀態列）

**位置：** 左上角
**尺寸：** 約 80 x 300（高 x 寬，原始規格）
※ 在 720x1280 畫布下實際視覺放大為約 130 x 380 較舒適
**顯示內容（由上而下）：**
- 頭像（含等級徽章 Lv.XX）
- 名稱
- **稱號（Title）— 名稱下方、經驗值上方**
- 經驗值 Bar（不顯示數字）
- 背板
- 未讀紅點（含未讀數字，附在頭像右上角，**不顯示信箱 icon**）

**不顯示：**
- ❌ 玩家 ID
- ❌ EXP 數字
- ❌ 信箱 icon

**互動：**
- 點擊整條 Bar → 展開主選單（包含信箱入口）
- 右側 `‹` 按鈕 → 收合 Bar 到畫面外，只露出 `›` 小拉柄
- 點 `›` 拉柄 → 重新展開 Bar

### 主選單（Main Menu）

點擊 Status Bar 後展開，包含以下頁面：

1. **個人資料** — 頭像 / 背板 / 暱稱設置
2. **信箱** — 系統訊息、未讀提醒
3. **排行榜** — TurnOver / 得分
4. **成就 / 任務** — 每日任務、遊戲攻略成就
5. **機台選擇** — 等級解鎖機台清單

## Prototype 頁面規劃

| 頁面 | 說明 |
|------|------|
| 浮動 Status Bar | 常駐左上，顯示基本資訊 |
| 主選單 | 點擊 Bar 後展開 |
| 個人資料頁 | 頭像 / 背板 / 暱稱編輯 |
| 信箱頁 | 訊息列表、已讀未讀 |
| 排行榜頁 | Tab 切換 TurnOver / 得分 |
| 成就頁 | 任務列表、進度、獎勵預覽 |
