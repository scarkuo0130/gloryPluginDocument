✓ 名稱 / 稱號 跑馬燈規格（已實作於 index.html A · status-profile）

當名稱或稱號文字寬度超過所在容器時，啟動由左到右的跑馬燈循環，避免被 ellipsis 截斷讓使用者看不到完整內容。

📌 套用範圍 = 僅 A · status-profile（index.html 與本文件 demo 一致）。B–G 變體評估後暫不套用（理由詳見下方表格）。A demo 填入長字串以展示效果，其他變體 demo 維持原本短字示意。

觸發條件

項目規則
判斷邏輯scrollWidth > clientWidth × ratio + 1（純粹比較容器與文字寬度，與字數無關）
觸發前提目標元素必須有 overflow:hidden; white-space:nowrap; 且容器寬度有上限
name 的 ratio0.6（壓縮可視寬以放大滑動量；用於固定寬 flex slot，例如 A 的 180px）
title 的 ratio1.0（只有真的溢出才觸發；chip 自動長到撞 max-width 才會啟動）
滑動距離innerWidth - clientWidth × ratio，動態量測

節奏（9 秒 loop）

階段時間動作
① 頭部停留0 – 3stransform: translateX(0)，文字頭部完整可見讓使用者閱讀
② 線性捲動3s – 6stranslateX(0) → translateX(-distance)，linear easing
③ 尾部停留6s – 9stranslateX(-distance)，尾部完整可見讓使用者閱讀
④ 循環9s →跳回 0，重複（無過渡，因為頭尾各停 3s 視覺已連續）

實作要點

  • 用 Web Animations API 不用 CSS @keyframes：父層 .canvas 有 transform: scale() 形成 compositor context，CSS keyframes 的 transform 動畫會被推到 compositor 但**視覺不重繪**（JS 讀得到值、畫面卻不動）。WAAPI 走不同路徑、可靠。
  • 不使用 will-change: transform：與父層 transform 並存會強制獨立 layer，再加上 calc(var()) 容易卡在不重繪狀態。
  • 稱號 ✦ 前綴處理：若 title 用 ::before { content: '✦ '; }，marquee 啟動時 ::before 不會跟著捲，會跟內文重疊。解法：is-marquee 時 ::before { content: none; }，並把 ✦ 直接前綴到 inner span 的 textContent。
  • 動態文字更新時要重跑量測：rename / 輪播 / 頁面切換 / resize 都要呼叫 refreshXxxMarquee()，重建 inner span 和重算距離。
  • WeakMap 管理 animation 實例：每個 element 對應一個 Animation，re-apply 時先 cancel() 舊的，避免 leak。

實作要點

  • 父層不可 overflow: hidden：否則上半截會被裁掉。index.html 的 .status-profile 目前有 overflow: hidden，套用前需評估改成 overflow: visible 或將 .ach-stars 改放在外層 wrapper。

  • 未來若需動畫（成就解鎖時新增 ✮）：建議在新 span 上加 animation: starPop，並讓既有 ✮ 平移讓位（CSS transition on flex gap 即可）。

實作要點

  • row 高度必須鎖死：若 row 不顯式設 height，<img> 會以 intrinsic size（512×512）撐爆容器。align-self: stretch + aspect-ratio 無法強制 shrink 圖片，故必須由 --ttl-h 顯式喂進 row height。

📐 統一規格建議方向

  • 定義 3 級 chip：chip-sm（H、mq）、chip-md（E/F/G、列表用）、chip-lg（A、狀態列用）
  • 定義 2 級卡片：card-profile（C/D、含 EXP/VIP）、card-banner（B/I、含背景全鋪）
  • 確立稱號統一樣式 token：--title-style: pill | text
  • 確立等級統一樣式 token：--lv-style: badge | inline
  • 背板可讀性策略：根據文字密度決定是否加 overlay（密度高 → C/D 半透；低 → A/E 全鋪）
