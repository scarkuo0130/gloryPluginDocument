✓ E 重構規格（已確認）

E 的玩家資訊欄獨立為 .player-card.player-card--list，排名、數值改為 .lb-item row 的 sibling，移出資訊欄。

區塊原結構（混在一起）新結構（職責分離）
排名 + 趨勢 .lb-rank-wrap在 .lb-item 內、共用背板外移到 row 上、無背板
玩家資訊欄（avatar + Lv/名稱/稱號）分散在 .lb-item + .lb-item-top 中獨立成 .player-card--list、自帶背板
數值 + 單位 .lb-value-wrap在 .lb-item-top 內、共用背板外移到 row 上、無背板

📐 規格決策：背板（--player-bg）只覆蓋「玩家資訊欄」這一個視覺單位，排名 / 數值在玩家資訊欄外，視覺上是「列容器 row」的職責。其他成員（H/I 跑馬燈玩家 chip）也用同個 .player-card 家族標籤標識。

✓ F 重構規格（已確認）— 與 E 同模式

F 採用與 E 相同的「row container + 玩家資訊欄子層」模式，但不影響 G（active-player 場景仍用原 .lb-menu-row，不加 with-rank modifier）。

區塊原結構新結構
外層容器.lb-menu-row（自帶背板）.lb-menu-row.lb-menu-row--with-rank（透明 row）
排名 + 趨勢在 row 內、共用背板外移到 row 上、無背板
玩家資訊欄無獨立元素.player-card--list-mini、自帶背板
數值 .lb-menu-value在 row 內、共用背板外移到 row 上、無背板

📐 差異點：F 用 .player-card--list-mini（小尺寸，min-height: 40px、avatar 34px），E 用 .player-card--list（大尺寸，avatar 78px）。兩者結構模式相同，尺寸不同。

✓ E / F / G 統一規格家族（已確認）

E、F、G 屬於同一「玩家資訊欄」家族，共用 .player-card base，依場景需求選擇 size 變體：

版面變體 class場景背板處理外層 row
E.player-card--list排行榜列（大）暗膜疊背板有（rank + value）
F.player-card--list-mini選單預覽列（中）暗膜疊背板有（rank + value）
G.player-card--list-chip活躍玩家面板（純 chip）純背板（無暗膜）無

📐 規格決策：「背板套用對象 = 玩家資訊欄」是 EFG 共通法則。有 row container 的場景（E/F）疊暗膜保證 rank/value 可讀；無 row 容器 的場景（G）讓玩家背板直接顯示，視覺更突出。H（跑馬燈）獨立維護，不納入此家族。

⚠ 不一致與待統一的問題

  • C / D（profile-info-card）沒有 Lv 顯示，反而用 VIP LV 替代。其他 7 個版面都顯示 Lv → 應統一處理「Lv vs VIP」的關係（兩者是同概念還是分開？）
  • H（mq-user）順序與眾不同：Lv → 稱號 → 名稱（其他都是 Lv → 名稱 → 稱號）
  • 頭像尺寸跨度大：32px（mq-user）→ 80px（profile-card），共 6 種尺寸 → 可整理為 3 階規格（小 32-40 / 中 44-64 / 大 80）
  • 圓角值不一致：18 / 20 / 24 / 28 / 32 / 34 → 可統一為 18（列）/ 20（區塊）/ 32（chip）三檔
  • 等級顯示有兩種樣式：.status-level（純色文字）與 .lv badge（金橙漸層膠囊）→ 同一概念有兩種視覺
  • 稱號顯示有三種樣式：A 有膠囊外框；E/F/G 純色文字 ✦ 稱號；H 有膠囊外框 → 可統一稱號 chip 規格
  • 背板套用方式有 3 種：(1) 整個容器作為 background（A、B、E、F、G、H）；(2) 半透明疊加 35% opacity（C、D）；(3) 加黑膜降亮（I）→ 影響可讀性的策略不一致

📐 統一規格建議方向

  • 定義 3 級 chip：chip-sm（H、mq）、chip-md（E/F/G、列表用）、chip-lg（A、狀態列用）
  • 定義 2 級卡片：card-profile（C/D、含 EXP/VIP）、card-banner（B/I、含背景全鋪）
  • 確立稱號統一樣式 token：--title-style: pill | text
  • 確立等級統一樣式 token：--lv-style: badge | inline
  • 背板可讀性策略：根據文字密度決定是否加 overlay（密度高 → C/D 半透；低 → A/E 全鋪）
