當名稱或稱號文字寬度超過所在容器時，啟動由左到右的跑馬燈循環，避免被 ellipsis 截斷讓使用者看不到完整內容。

觸發條件

項目規則
判斷邏輯scrollWidth > clientWidth × ratio + 1（純粹比較容器與文字寬度，與字數無關）
觸發前提目標元素必須有 overflow:hidden; white-space:nowrap; 且容器寬度有上限
name 的 ratio0.6（壓縮可視寬以放大滑動量；用於固定寬 flex slot，例如 A 的 180px）
title 的 ratio1.0（只有真的溢出才觸發；chip 自動長到撞 max-width 才會啟動）
滑動距離innerWidth - clientWidth × ratio，動態量測

節奏（9 秒 loop）

階段時間動作
① 頭部停留0 – 3stransform: translateX(0)，文字頭部完整可見讓使用者閱讀
② 線性捲動3s – 6stranslateX(0) → translateX(-distance)，linear easing
③ 尾部停留6s – 9stranslateX(-distance)，尾部完整可見讓使用者閱讀
④ 循環9s →跳回 0，重複（無過渡，因為頭尾各停 3s 視覺已連續）

實作要點

  • 用 Web Animations API 不用 CSS @keyframes：父層 .canvas 有 transform: scale() 形成 compositor context，CSS keyframes 的 transform 動畫會被推到 compositor 但**視覺不重繪**（JS 讀得到值、畫面卻不動）。WAAPI 走不同路徑、可靠。
  • 不使用 will-change: transform：與父層 transform 並存會強制獨立 layer，再加上 calc(var()) 容易卡在不重繪狀態。
  • 稱號前綴處理（2026-06-11 已作廢）：稱號前綴符號已全面移除（見 M 區塊規格要點⑥），原 ::before 前綴與 marquee 疊字問題不再存在。
  • 動態文字更新時要重跑量測：rename / 輪播 / 頁面切換 / resize 都要呼叫 refreshXxxMarquee()，重建 inner span 和重算距離。
  • WeakMap 管理 animation 實例：每個 element 對應一個 Animation，re-apply 時先 cancel() 舊的，避免 leak。

不受此規則影響的變體

  • A / B（status-profile、menu-header）：玩家自身常駐顯示，需要稱號完整展示身份 → 維持顯示
  • C / D（profile-info-card）：個人資料 / 玩家資料頁，本身就是「展示頁面」 → 維持顯示

實作要點

  • HTML 不必改：稱號 chip 與徽章還是 render 到 DOM，純 CSS 隱藏（純 toggle 取消 rule 即可恢復）。如要從根本不渲染，請改用 renderer 條件式輸出。
  • name 不額外置中：name 行（.lb-name / .lb-menu-name）保留預設 flex-start 對齊，name 靠 info 欄左側、右側自然留空（info 欄為 flex:1，右側空間就是 info 欄剩餘寬度）。
  • name 垂直視覺看起來「正中」是 chip 預期：parent align-items: center 把塌縮成 1 行的 info 欄拉到 chip 垂直中心，與 avatar 中軸對齊，是好的視覺平衡。
  • H 為何沒有特別處理：.mq-user 本身就是 inline-flex 單列 shrink-to-content，沒有「空間多到需要對齊」的問題。

實作要點

  • row 高度必須鎖死：若 row 不顯式設 height，<img> 會以 intrinsic size（512×512）撐爆容器。align-self: stretch + aspect-ratio 無法強制 shrink 圖片，故必須由 --ttl-h 顯式喂進 row height。
  • border 1.5px round 成 1px：所有稱號 chip 用 1.5px solid，瀏覽器 computed border-width 實際是 1px 而非 1.5px，calc 時要算 1+1=2px。
  • icon 統一：所有變體用同一張 award_1060795.png，視覺意義交給未來成就 / 階級系統決定（目前是 placeholder）。
  • 稱號為「無」時須同步隱藏 .ttl-row：避免徽章單獨懸空。在 index.html 的稱號切換 JS（titleOption、openPlayerProfile、rename）裡，hide title 時必須一併 hide .ttl-row。
  • 稱號改用 inline-block 即可，不要保留原本的 align-self / margin：margin 須移到 .ttl-row（B 的 margin-bottom、C/D 的 margin-top），否則會在 inline-flex 內錯位。
